## Reporting a Vulnerability

1. On GitHub, navigate to the main page of the repository.
   https://github.com/visdb-dev/seesaw
2. Click `🛡️ Security and quality`
3. Under Overiew, find `Private vulnerability reporting`
   Click: `See reported vulnerabilities`
4. Click button `New draft security advisory`
5. Follow the instruction and fill in the form.
   Finally click button `Create draft security advisory`

Undetermined at this time
- how often to expect to get an update on a reported vulnerability
- what to expect if the vulnerability is accepted or declined, etc.
